# 🎶 Metaphor

K-POP 팬덤을 위한 뮤직 플랫폼

🔗 [Metaphor 사이트 바로가기](https://metaphor-8079a.web.app/)

Metaphor는 K-POP 팬덤 문화를 한 공간에서 즐길 수 있도록 제작한 플랫폼 웹 서비스입니다.  
아티스트 정보, 음악 차트, 매거진, 댓글과 좋아요 기능 등을 통해 팬들이 다양한 활동을 한 곳에서 경험할 수 있도록 구성했습니다.

---

- **진행 기간**: 2025.02 (1개월)

- **프로세스**: 기획 → 디자인(Figma) → 퍼블리싱 → 기능 구현 → Firebase 배포

## 👤 팀원별 역할

- **PM 현윤섭**  
  로고 및 브랜드 아이덴티티를 제작하고, WBS를 기반으로 일정 관리와 역할 분배를 총괄했습니다.  
  GitHub를 통한 협업 프로세스를 관리하며 팀원 간 소통을 책임졌습니다.  
  메인 홈 페이지를 구현하며 핵심 콘텐츠 배치, 섹션 간 흐름, 사용자 친화적 인터페이스 설계를 주도했습니다.

- **정휘찬**  
  회원가입·로그인·마이페이지의 기본 UI를 제작하여 계정 기능의 기초 틀을 마련했습니다.  
  사용자 계정의 흐름(가입 → 로그인 → 마이페이지)을 설계하여 프로젝트 전반의 기초 구조를 마련했습니다.  
  오류 상황에서 안내 문구와 피드백을 보완해 사용자가 계정 기능을 보다 직관적으로 이해할 수 있도록 개선했습니다.

- **장효아**  
  전체 UI 디자인의 통일성을 검토하고 각 페이지의 스타일을 조율했습니다.  
  푸터 영역을 구현하여 프로젝트의 공통 레이아웃을 보완했으며, 상단으로 이동할 수 있는 업버튼 기능을 추가했습니다.
  아티스트 상세 페이지를 담당하여 개별 아티스트 프로필, 영상, 음악 정보, 팬톡을 보여주는 구조를 구현했습니다.  
  로그인·회원가입·마이페이지에 로컬스토리지를 연동하여 사용자 정보 저장 및 로그아웃 기능까지 지원했습니다.

- **구여진**  
  프로젝트 공통 레이아웃인 헤더 영역을 구현하여 모든 페이지에서 일관된 네비게이션 환경을 제공했습니다.  
  차트 데이터를 위한 JSON DB를 구축하고, TOP10·주간·월간 카테고리를 분리해 음악 차트를 구성했습니다.  
  차트 페이지에서는 데이터 로딩, 음악 재생 기능을 구현하여 기본적인 음악 차트 경험을 제공했습니다.  
  또한 아티스트 리스트와 매거진 페이지 등 긴 목록형 콘텐츠에 페이지네이션 기능을 추가하여 탐색성을 개선했습니다.

## 🛠️ 기술 스택

- **Frontend:** HTML, SCSS, JavaScript
- **Library:** jQuery (Slick Slider)
- **Design & Collaboration:** Figma, GitHub, Slack
- **Deployment:** Firebase Hosting

---

## 📌 주요 기능

- **메인 홈**: 프로젝트의 전체 진입점으로, 로고·네비게이션을 포함한 브랜드 아이덴티티와 핵심 콘텐츠를 소개
- **아티스트 정보**: 아티스트 리스트 및 상세 페이지에서 프로필, 음악, 미디어 영상 제공
- **음악 차트**: TOP10 / 주간 / 월간 카테고리 기반 음악 차트, 음원 재생 및 좋아요 기능
- **매거진**: K-POP 관련 기사형 콘텐츠, 페이지네이션 적용
- **회원가입 / 로그인 / 마이페이지**: 기본 UI 및 로컬스토리지를 활용한 로그인/로그아웃 구조 구현
- **공통 레이아웃**: 헤더, 푸터 등 전역 UI 구성

---

## ✅ 구현 포인트

- 기초적이지만 팬덤 플랫폼의 전반적 구조(아티스트·차트·매거진·계정)를 한 프로젝트에서 통합
- JSON 기반 데이터 연동 및 UI 반영을 통해 동적 콘텐츠 구현 경험
- 로컬스토리지를 이용해 로그인 및 사용자 정보 관리 로직을 학습
