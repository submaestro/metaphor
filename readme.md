# 🎶 Metaphor

K-POP 팬덤을 위한 뮤직 플랫폼

🔗 [Metaphor 사이트 바로가기](https://metaphor-8079a.web.app/)

Metaphor는 K-POP 팬덤 문화를 한 공간에서 즐길 수 있도록 제작한 플랫폼 웹 서비스입니다.  
아티스트 정보, 음악 차트, 매거진, 댓글과 좋아요 기능 등을 통해 팬들이 다양한 활동을 한 곳에서 경험할 수 있도록 구성했습니다.

## 📌 주요 기능

- **홈(Home)**  
  프로젝트의 메인 페이지로, 서비스 소개와 핵심 콘텐츠를 직관적으로 배치.  
  전체 레이아웃의 기반이 되는 구조를 잡고, 다른 페이지로의 진입 동선을 설계.

- **아티스트(Artist)**

  - **리스트**: 여러 아티스트를 아이콘 카드 형태로 나열하고, 페이지네이션으로 긴 목록도 효율적으로 탐색.
  - **상세**: 아티스트별 프로필, 활동 정보, 영상·음악, 팬톡(Fan Talk) 등 팬덤 활동을 집중할 수 있는 단일 페이지로 구현.

- **차트(Chart)**  
  TOP10 / 주간 / 월간 데이터를 JSON 기반으로 불러와 차트 형태로 구성.  
  음악 재생과 좋아요 기능을 통해 기본적인 음악 차트 경험 제공.

- **매거진(Magazine)**  
  K-pop 관련 소식을 카드형 UI로 배치.  
  페이지네이션을 도입해 다수의 기사 콘텐츠를 나누어 보여주며 탐색성을 높임.

- **회원가입·로그인·마이페이지**
  - **회원가입/로그인**: 입력값 유효성 검증과 안내 문구로 기본적인 계정 흐름 구현.
  - **마이페이지**: 사용자 정보 확인과 로그아웃 기능을 제공하여 계정 관리의 기초 틀 완성.

## ✅ 구현 포인트

- 팬덤 플랫폼의 전반적 구조(아티스트·차트·매거진·계정)를 한 프로젝트에서 통합하여 설계 및 구현
- JSON 기반 데이터 연동과 UI 반영을 통해 동적 콘텐츠를 구성하고 사용자 경험을 강화
- 로컬스토리지를 활용해 로그인 및 사용자 정보 관리 로직을 구현하며 계정 기능을 확장
